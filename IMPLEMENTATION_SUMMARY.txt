HOW TO TEST THE FIXES
================================================================================

1. Install Dependencies:
   $ cd backend
   $ pip install -r requirements-dev.txt

2. Run Test Suite:
   $ pytest tests/ -v
   
   Expected: All 15+ tests pass ✅

3. Test Rate Limiting (Manual):
   $ curl -X POST http://localhost:8000/api/v1/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"test@test.com","password":"wrong"}'
   
   Expected: After 5 failed attempts, HTTP 429 response

4. Test Password Policy (Manual):
   $ curl -X POST http://localhost:8000/api/v1/users \
     -H "Authorization: Bearer <admin_token>" \
     -H "Content-Type: application/json" \
     -d '{
       "email":"test@test.com",
       "full_name":"Test",
       "password":"weak",
       "role":"admin"
     }'
   
   Expected: HTTP 422 with validation error

5. Test Audit Logging (Manual):
   $ curl -X GET http://localhost:8000/api/v1/audit/logs \
     -H "Authorization: Bearer <admin_token>"
   
   Expected: JSON array of audit log entries
